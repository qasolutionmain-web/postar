Postar 설치 안내 (PWA)

1. 폴더 전체를 HTTPS 웹 서버에 올립니다 (GitHub Pages, Netlify, 사내 서버 등).
   - 로컬 테스트: 폴더에서  npx serve .  또는  python -m http.server 8080  실행 후 http://localhost:8080 접속
2. PC (Chrome / Edge): 주소창 오른쪽의 [앱 설치] 아이콘 클릭 → 시작 메뉴·바탕화면에 Postar가 추가되고 별도 창으로 실행됩니다.
3. Android (Chrome): 메뉴 ⋮ → [앱 설치] 또는 [홈 화면에 추가]
4. iPhone (Safari): 공유 버튼 → [홈 화면에 추가]

※ 한 번 실행한 뒤에는 오프라인에서도 열립니다. 오프라인일 때는 웹폰트 대신 시스템 글꼴로 표시됩니다.
※ index.html을 더블클릭해 바로 열어 볼 수도 있지만, 이 방식으로는 설치할 수 없습니다.
※ 이 버전은 프로토타입입니다. 실제 POP3/SMTP 송수신은 하지 않으며, 표시되는 메일은 데모 데이터입니다.
